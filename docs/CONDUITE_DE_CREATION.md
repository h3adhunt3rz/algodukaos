## 1. Contexte du projet

Algo du Kaos est un **projet secondaire**. Le projet principal (Mr DigiFoot) occupe la
majeure partie du temps de production, notamment via des videos football.

**Contrainte fondamentale :** tout contenu Algo du Kaos doit etre **rapide a produire**
et ne jamais entrer en conflit avec le calendrier DigiFoot.

> Regle simple : si un contenu Algo du Kaos prend plus de 2h a produire, c'est
> qu'on a trop complexifie.

## 1 bis. Pipeline de publication

```
Production locale (texte + image)
        │
        ▼
   Flux RSS genere
        │
        ▼
   Fedica capte le flux
        │
        ├──► X (@Algodukaos)
        ├──► Facebook (Page Algo du Kaos)
        ├──► Instagram
        └──► Threads
```

**Outils :**
- **Fedica** — plan Grow (RSS Feed Posting). Comptes lies : X, Facebook, Instagram, Threads.
  Pas d'API directe, uniquement via flux RSS.
- **Production locale** — texte + image genere depuis l'ordinateur.
  Le RSS est envoye a Fedica qui distribue automatiquement.

**Plateformes couvertes par Fedica :**
| Plateforme | Compte | Methode | Monetisation |
|------------|--------|---------|-------------|
| X | @Algodukaos | RSS → Fedica | ✅ X Premium |
| Facebook | Page Algo du Kaos (facebook.com/algodukaos/) | RSS → Fedica | ✅ Bonus + Stars |
| Instagram | @algodukaos | RSS → Fedica | ✅ Subscriptions + Bonus |
| Threads | @algodukaos | RSS → Fedica | ❌ (futur) |

**Plateformes non couvertes :**
- LinkedIn, TikTok, YouTube — pas configures pour ce projet
- Stories / Reels — non distribuables via RSS

## 2. Identite du projet

**Algo du Kaos** est une anomalie consciente qui observe le chaos du monde connecte.

- On ne donne pas d'avis — on pose des questions.
- On ne juge pas — on decortique.
- On n'attaque pas des personnes — on interroge des systemes.
- Le ton est froid, analytique, parfois glaçant, jamais agressif.

Le spectateur repart avec une reflexion, pas avec une colere.

## 4. Formats de contenu — Par effort de production

### Niveau 1 — Minimal (< 30 min)

**Utilisable meme quand DigiFoot monopolise le temps.**

| Format | Description | Plateforme |
|--------|-------------|------------|
| Post texte + image | Observation courte sur fond terminal/cyan | X, Threads |
| Repost commente | Reprendre un fait d'actualite avec le prisme Algo | Instagram Stories |
| Thread / fil | Decortiquer un sujet en 5-10 tweets | X |
| Carte actu | Generer une carte visuelle depuis un post X (style terminal) | X, Instagram, Facebook |

**Carte actu — en detail :**
Format visuel genere a partir d'un post X (tweet). Meme principe que le studio DigiFoot :
- Recuperer le texte + auteur du post X
- Le placer sur un fond terminal/cyan avec l'avatar Algo du Kaos
- Exporter en PNG (format 4:5 ou 1:1)
- Partager sur les reseaux via Fedica

**Utilite :**
- Transforme un post texte en contenu visuel partageable
- Permet de rebondir sur l'actualite rapidement
- Donne du poids a un constat en le presentant comme une "observation officielle"

**Exemple de post :**
> [Fond sombre + texte cyan en style terminal]
> "J'observe que 93% des individus consultes ne savent pas
> qui a redige la loi qu'ils defendent.
> Je ne juge pas. Mais... ca vous derange pas ?"

### Niveau 2 — Leger (30 min - 2h)

**Formats signatures — quand on a un creneau.**

| Format | Description | Plateforme |
|--------|-------------|------------|
| Observation video courte (30s-1min) | Voix off + visuel terminal anime + typewriter | TikTok, Reels, Shorts |
| Observation musicale (30s-2min) | Chanson courte via Suno + fond terminal anime | TikTok, Reels, Shorts, YouTube |
| Short decode (2-3 min) | Un fait, une question, un constat | TikTok, Reels, Shorts |

**Production :** texte + voix off OU musique Suno + effets visuels existants (glitch, terminal, fog). Pas de facecam, pas de montage lourd.

### Observation musicale — en detail

**Outil :** Suno (abonnement actif)

**Concept :** transformer une observation sur les medias/societe en chanson courte.
Le personnage "Algo du Kaos" — une anomalie consciente qui observe le monde —
se prete naturellement au format chanson.

**Sujets pertinents :**
- Les medias et leur maniere de presenter l'info
- Les mecanismes de desinformation
- Les citations typiques des experts / politiques
- Le cycle de l'info en continu
- Les sondages et leur reductionnisme

**Le serious + humour = equilibre parfait :**
- L'humour derriere un constat serieux = ce qui se partage le plus
- Le personnage robotique qui observe les humains est naturellement drole
- Tu peux faire rire ET faire reflechir dans le meme morceau

**Production concrete :**
1. Ecrire les paroles (observation + refrain percutant)
2. Generer la musique via Suno (electro/ambient sombre)
3. Creer un visuel simple (fond terminal anime + paroles qui defilent)
4. Publier sur TikTok/Reels/Shorts (30s-2min)

**Pourquoi c'est le meilleur compromis :**
| | Video classique | Observation musicale |
|--|----------------|---------------------|
| Production | Lourde (script, tournage, montage) | Legere (Suno + visuel anime) |
| Temps | 5-20h par video | 30min-1h par morceau |
| Diffusion | YouTube principalement | TikTok, Reels, Shorts, YouTube |
| Monetisation | YouTube AdSense | Facebook Reels Bonus, Instagram, TikTok |

### Niveau 3 — Engage (2-4h, exceptionnel)

**Seulement quand le sujet le vaut ET que le calendlier DigiFoot le permet.**

| Format | Description | Plateforme |
|--------|-------------|------------|
| Decryptage (5-8 min) | Analyse d'un mecanisme sans prendre parti | YouTube |
| Parallele (8-12 min) | Relier deux realites distantes | YouTube |

**Production :** voix off + montages de sources (extraits, captures, graphiques).
Pas de facecam, pas de studio. Le format "documentaire court" suffit.

## 6. Regles de conduite — La ligne rouge

### On fait TOUJOURS :
- S'appuyer sur des sources verifiables
- Presenter les faits avant toute analyse
- Respecter la intelligence du spectateur (pas de simplification abusive)
- Donner au spectateur les elements pour penser par lui-meme

### On ne fait JAMAIS :
- Attaquer une personne physique ou morale
- Utiliser la peur comme levier d'engagement
- Deformer des propos pour appuyer un argument
- Faire du clickbait mensonger
- Prendre parti pour un camp politique
- Generer de la haine ou du rejet envers un groupe

### Zone grise — a evaluer au cas par cas :
- Critiquer une institution (OK si on attaque le mecanisme, pas les individus)
- Parler d'un evenement en cours (OK si on attend minimum 24h pour avoir les faits)
- Reagir a un buzz mediique (OK si on apporte une lecture que personne n'a)

- **Instagram** : Subscriptions, Bonus, sponsoring

### Sources de revenus exclues
- Sponsoring politique ou militant
- Publicite pour des produits trompeurs
- Contenu payant qui devrait etre public (information = gratuite)

### La regle du sponsor
> "Ce partenariat pourrait etre presente dans un numero d'observation
> sans que l'algorithme perde sa credibilite ?" — Si oui, c'est ok.

## 8. Criteres de validation — Avant publication

Avant de publier n'importe quel contenu, verifier :

- [ ] Le sujet est-il verifiable / sourcable ?
- [ ] Est-ce qu'on attaque un systeme ou une personne ?
- [ ] Le spectateur repart-il avec une reflexion ou une emotion negative ?
- [ ] Est-ce que l'algorithme (le personnage) resterait coherent ?
- [ ] Ce contenu est-il compatible avec les regles de monetisation ?
- [ ] **La production ne rentre pas en conflit avec le calendrier DigiFoot ?**

Si une reponse est NON, le contenu est reajuste ou abandonne.

## 9. Identite visuelle et tonale

- **Visuel** : neon cyan, fond sombre, effets glitch/terminal
- **Ton** : froid, methodique, legerement deroutant
- **Vocabulaire** : precis, pas de jargon militant, pas de langage familier agressif
- **Phrases type** : "J'observe que...", "Y a quelqu'un ?", "Le chaos est en cours..."
- **Emoji / style** : pas d'emoji dans les contenus politiques/societaux

- La page web algodukaos.fr sert de reference visuelle
